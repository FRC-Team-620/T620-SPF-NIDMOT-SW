# Graphify — codebase knowledge graph

This folder is generated by [Graphify](https://graphify.net). It maps the robot codebase into a queryable knowledge graph.

## Why it exists

Instead of digging through files to understand how subsystems connect, you can ask the graph directly. Useful for onboarding, refactors, and tracing dependencies across the drive/shooter/intake/indexer subsystems.

## Files

| File | What it is |
|------|------------|
| `graph.html` | Interactive visualization — open in any browser, no server needed |
| `GRAPH_REPORT.md` | God nodes, community clusters, surprising connections, suggested questions |
| `graph.json` | Raw graph data |

## Setup (one-time)

Requires `uv` (install via `winget install astral-sh.uv`), then:

```
uv tool install graphifyy
graphify install
graphify hook install   # auto-rebuild graph on every git commit
```

## Usage

```
/graphify .                                    # rebuild the graph
/graphify query "what depends on DriveConstants?"
/graphify query "how does shooter get commanded?"
/graphify path "RobotContainer" "Drive"
/graphify . --update                           # incremental update after code changes
```

All commands run inside Claude Code (VS Code extension or CLI).
